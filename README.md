FAQ-бот на 5 вопросов
Чат в терминале, который отвечает на 5 заранее известных вопросов.

Лёгкий кейс для репетиции. Хватит скрипта на 30–60 минут. Стек любой.

Что сделать:

faq.txt в репо: 5 пар вопрос–ответ про репетицию (время, команда, трек, сдача, призы).
Пользователь пишет вопрос → бот находит ближайший и печатает ответ. Если не похоже — «не знаю».
Достаточно совпадения по ключевым словам. RAG не нужен.
